# 开发说明

## 项目结构

- `manifest.json`：Chrome 扩展配置与权限。
- `src/`：后台服务、持仓面板、平台数据源和 GMGN 追踪桥接。
- `assets/`：静态资源。
- `test/`：Node 自动化测试和浏览器合成页面。

扩展直接加载源码，无需构建。安装步骤见 [README](../README.md)。

## 自动化测试

使用 Node.js 22 或更高版本，无需安装第三方 npm 依赖：

```bash
npm test
```

检查 JavaScript 语法和补丁格式：

```bash
for file in src/*.js; do node --check "$file" || exit 1; done
git diff --check
```

测试使用模拟平台响应与合成数据，不会向真实 GMGN 页面推送测试交易。自动化测试通过不代表所有线上交易都能成功显示。

## 公开版运行配置

公开版关闭本地诊断采集、交易收发记录存储和诊断接口，不提供诊断页面。存储中的旧开关或运行时消息不能开启这些功能；正常交易投递确认与重试继续工作。

自动化测试保留隔离的诊断分支单元测试，同时使用实际发布配置验证诊断关闭后的持仓查询与交易推送。

修改代码后，在 Chrome 扩展管理页面重新加载扩展，并完整刷新已打开的 GMGN 页面。

## Pump 交易补漏

Alerts 中 EVM 交易的 `walletAddress` 可能是 Pump 的 Solana 主页地址。后台从官方用户接口核对主页地址与用户 ID，再映射到 `canonical_evm_wallet`；REST 和 NATS 共用查询缓存及交易去重。

GMGN 存在接收页面时，EVM 个人动态与 Alerts 对账一起运行；可见页面每轮约 30 秒检查一次。每轮轮换检查最多 20 个关注账号，并发不超过 4，仅读取个人动态首屏。仅处理启动后且不超过 60 秒的交易，经对应钱包链上回执确认、金额达到 10 美元后投递。大关注列表、上游索引延迟或 RPC 故障仍可能导致遗漏，不把历史记录改时间补发。查询不额外订阅钱包 WebSocket，不拉取币种元数据，关闭推送或会话切换会丢弃旧响应。

## Arc 持仓与交易追踪（1.0.4）

GMGN 的 `/arc/token/<address>` 页面映射为网络 ID `5042`，Fomo 请求使用链名 `arc`。Fomo 的 `/hodlers/top`、用户资料与 Pump 的 `/mint-positions/<mint>` 继续复用现有持仓流程，平台卡片合并及排序规则不变。

Arc 原生 USDC 预部署地址 `0x3600000000000000000000000000000000000000` 按 6 位精度作为现金及支付币处理。交易追踪使用 `5042 → arc` 接入 GMGN 原生追踪；没有为 Arc 修改提示音、卡片布局或去重规则。

## Pump 支付金额与 HyperEVM（1.0.4）

Pump 交易追踪增加 `999 → hyperevm`，复用现有 EVM 用户钱包映射、个人动态对账和回执验证。HyperEVM RPC 使用 `https://rpc.hyperliquid.xyz/evm`；Fomo 持仓查询链保持原范围。

Alerts 保留有效的支付金额、支付币地址及符号。缺失时不向 GMGN 发送伪造的 `quote_amount=0` 和支付币地址组合，让 GMGN 沿用美元金额换算展示；原生币价格不可用时由 GMGN 显示 `--`。补齐前的原生币数量是 GMGN 的换算展示，不冒充链上精确支付数量。

仅对已观察到的最近 60 秒 Pump 交易补查一次个人动态首屏；并发最多 2、等待队列最多 32、尝试记录最多 128，同一主页共享进行中的请求，个人动态请求超时 3 秒，不增加轮询或重试。EVM 核对官方用户 ID 与钱包，按链、交易哈希、钱包、代币和方向精确匹配一条 SWAP，再补齐原行的支付字段。关闭页面或切换会话后丢弃结果；不阻塞交易首次投递。已确认显示的原行最多等待 30 秒，补齐不重复推送、改时间或响铃。

## Pump 市值补全

实时 Alerts 保留平台提供的供应量和市值字段；缺失时，由 GMGN 页面调用自己的 `/api/v1/token_info_brief` 接口。复用 GMGN 的请求包装器、登录态和响应解析；按链与代币地址校验返回结果，`total_supply` 已是人类单位，不能再次除以 decimals。此步骤不请求链上 RPC。

请求按链和代币去重，最多同时进行 16 个，每个最多等待 6 秒；成功供应量缓存 30 秒，失败缓存 3 秒，缓存最多 256 个。GMGN 当前供应量结合原始成交价格计算展示市值，不用当前价格覆盖成交价格，也不将观察值标记为历史区块供应量。

交易立即投递，元数据完成后更新相同原生记录，不重写交易时间、金额或重播声音。已确认显示的 Pump 记录最多等待 30 秒补充市值；首次投递和声音仍使用 5 秒期限。接口不可用或返回无效数据时保留交易，市值可能为空；关闭推送、取消关注或切换会话后不应用迟到的更新。

# 开发说明

## 项目结构

- `manifest.json`：Chrome 扩展配置与权限。
- `src/`：后台服务、持仓面板、平台数据源和 GMGN 追踪桥接。
- `assets/`：静态资源。
- `test/`：Node 自动化测试和浏览器合成页面。

扩展直接加载源码，无需构建。安装步骤见 [README](../README.md)。

## 自动化测试

使用 Node.js 22 或更高版本，无需安装第三方 npm 依赖：

```bash
npm test
```

检查 JavaScript 语法和补丁格式：

```bash
for file in src/*.js; do node --check "$file" || exit 1; done
git diff --check
```

测试使用模拟平台响应与合成数据，不会向真实 GMGN 页面推送测试交易。自动化测试通过不代表所有线上交易都能成功显示。

## 公开版运行配置

公开版关闭本地诊断采集、交易收发记录存储和诊断接口，不提供诊断页面。存储中的旧开关或运行时消息不能开启这些功能；正常交易投递确认与重试继续工作。

自动化测试保留隔离的诊断分支单元测试，同时使用实际发布配置验证诊断关闭后的持仓查询与交易推送。

修改代码后，在 Chrome 扩展管理页面重新加载扩展，并完整刷新已打开的 GMGN 页面。

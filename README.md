# GMGN Fomo Pump Panel

**在 GMGN 看盘，一起看 Fomo / Pump 持仓和关注用户的买卖动态。**

GMGN Fomo Pump Panel 是一款 Chrome 扩展，把 Fomo / Pump 的持仓信息放到 GMGN 币种页面，并将你在这两个平台关注用户的买卖动态接入 GMGN 原生「追踪」。少切几个页面，在熟悉的看盘界面里了解谁还在持仓、关注的人有什么新动作。

支持 Ethereum、BSC、Base、Solana 和 Robinhood Chain。

## 主要功能

### 查看持仓与评论

打开 GMGN 币种页面，即可在浮窗或侧边栏查看：

- Fomo 当前持仓用户，以及 Pump 上有 Callout Thesis 且仍有持仓的用户。
- 持仓金额、盈亏、平均入场市值、持仓占比和评论等信息，以平台提供的字段为准。
- 按持仓金额从高到低排列的用户卡片，快速了解主要持仓者。

Fomo 与 Pump 分开展示用户卡片，顶部汇总只统计 Fomo。Fomo 返回结果达到 100 条时会标注 `Top 100`。

### 在 GMGN 追踪关注用户

你在 Fomo / Pump 关注用户的新买卖动态会进入 GMGN 原生「追踪」列表，并沿用 GMGN 的通知与声音设置。无需另开一套交易列表。

可以直接在持仓卡片上关注或取消关注用户，也可以通过侧边栏底部的「推送追踪」开关暂停推送。

### 按自己的习惯看盘

- **浮窗**：在币种页面直接查看，可拖动、缩放和折叠。
- **侧边栏**：点击扩展图标打开，切换币种时跟随更新。
- **钱包地址复制**：点击用户名，解析并复制对应链的钱包地址；无法可靠确认时会提示失败。
- **更多信息**：通过 `Feed` 查看买卖与转账，通过 `About` 查看项目简介、行情和社交链接。

## 安装与开始使用

需要 **Chrome 116 或更高版本**，目前通过加载本地扩展安装。

1. 在本仓库点击 **Code → Download ZIP**，下载后解压；也可以使用 Git 克隆仓库。
2. 在 Chrome 地址栏输入 `chrome://extensions`，打开扩展管理页面。
3. 开启右上角的「开发者模式」，点击「加载已解压的扩展程序」。
4. 选择解压后的项目文件夹，也就是包含 `manifest.json` 的目录。
5. 在同一浏览器中登录 [Fomo](https://fomo.family/) 和 [Pump](https://pump.fun/)，以使用对应平台的功能。
6. 打开或完整刷新 [GMGN](https://gmgn.ai/) 的币种页面，即可看到浮窗；点击扩展图标可打开侧边栏。

**使用交易推送前，请在 GMGN「追踪」的平台筛选中，为需要接收推送的每条链勾选「其他」。** Fomo / Pump 的交易会归入该分类；多链「全部」模式也沿用各链设置。

### 更新插件

下载并解压新版本，替换原扩展目录中的文件；如果使用 Git 安装，则更新本地仓库。在 `chrome://extensions` 中点击扩展的重新加载按钮，然后**完整刷新所有已打开的 GMGN 页面**。

请保留安装目录，Chrome 会持续从该目录加载扩展。

## 登录与隐私

- 使用浏览器中已有的 Fomo / Pump 登录态，无需向插件提供私钥或助记词。
- Fomo 登录凭据保存在当前浏览器的扩展本地存储中，不会发送给 GMGN；Pump 请求复用现有登录 Cookie。
- 链上查询与地址验证均为只读，插件不会代你发送交易或自动下单。
- 关注和取消关注会同步到对应平台账号。
- 公开版关闭本地诊断采集，不提供诊断页面。

## 常见问题

**为什么没有持仓数据？**

先确认已在同一浏览器中登录对应平台，并完整刷新 GMGN 页面。Pump 仅展示有 Callout Thesis 且仍持仓的用户，因此不一定每个币都有结果。若侧边栏提示登录失效，按提示重新登录。

**为什么关注用户的交易没有显示？**

确认「推送追踪」已开启、对应平台登录态有效，并检查交易所属链的平台筛选是否勾选了「其他」。刚启动时的旧交易不会作为新交易重新提醒。若仍有遗漏，请提交反馈。

**为什么有交易记录，但没有声音？**

插件沿用 GMGN 对应链的追踪声音设置，请先确认 GMGN 已开启声音。

**为什么复制钱包地址失败？**

部分用户的数据不足以唯一确认钱包地址，插件会提示 `Copy failed`，不会返回猜测结果。
